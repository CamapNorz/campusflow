# CampusFlow

繁體中文畢業專題管理網站，使用 React、Vite 與 Firebase。

**接手開發請先讀 [HANDOFF.md](HANDOFF.md)。真正的應用程式在內層 `campusflow/`，請勿在此 Git 根目錄執行 npm 指令。**

```sh
cd campusflow
npm ci
npm run dev -- --host 127.0.0.1
```

已有相依套件時可直接啟動。開啟終端顯示的網址，加上 `/?demo=1` 即可使用示範資料。
