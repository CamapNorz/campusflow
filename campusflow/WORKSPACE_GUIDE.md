# CampusFlow 使用與開發指南

交接狀態、已推送版本與待驗收事項統一記錄於 [HANDOFF.md](../HANDOFF.md)。本文的「本輪」驗證指先前功能改版階段，不代表每次文件更新都重跑驗證。

## 啟動

在此目錄執行 `npm ci`，再執行 `npm run dev -- --host 127.0.0.1`，開啟終端顯示的網址。

- `/?demo=1`：組長示範，可新增、編輯、更新任務狀態與匯出。
- `/?demo=1&role=member`：組員介面。
- `/?demo=1&role=teacher`：指導老師介面。
- `/?demo=1&view=gantt`：直接開啟示範甘特圖。

示範資料存在記憶體，重新整理即還原；不訂閱或寫入 Firebase。改名、問題回報與老師加入組別僅顯示示範提示。正式模式保留原 Firebase 專案與 Google 登入。

## 新版操作

- **工作室總覽**：專題進度、逾期提醒、本週完成／MVP、近期截止、成員負擔與三欄看板。
- **所有任務**：搜尋標題、內容或組員；保留各項篩選。可切換截止日期、重要度及新增日期排序，快速查看我的任務、清除篩選，並以 CSV 匯出目前結果。
- **新增與編輯**：任何頁面都可新增任務，總覽及列表均能開啟編輯視窗。保留指派、類型、重要度、詳細內容、開始／截止／完成日期與原權限。新增及編輯會攔截反向日期；操作失敗會保留輸入並顯示錯誤。刪除會先確認。
- **行事曆**：月份切換、回到今天、日期任務、狀態圖例；搜尋、篩選和排序與所有任務共用。
- **專題甘特圖**：依實際起訖時間繪製，明列日期與時分；保留順序、顏色、篩選。可指定起迄日或配合任務範圍，切換日、週、月及配合寬度。跨區間任務會裁切顯示，不會消失。相同起訖時間以菱形表示；缺少有效起訖或日期反向者另計數提示。無排程任務時預設顯示從今天起兩週。
- **團隊排行榜**：保留重要度積分、逾期扣分、完成數與同分排名。
- **帳號與協作**：保留 Google 登入、建立／加入空間、老師審核與組別切換、代碼複製、每 24 小時改名限制、問題回報與 Discord worker。Discord 設定見 [BOT_SETUP.md](BOT_SETUP.md)。

## 驗證

```sh
npm run lint
npm test
npm run build
```

12 個單元測試涵蓋搜尋、排序、動態日期範圍、日期驗證、CSV 引號／換行／公式防護，以及甘特圖分鐘精度、跨區間裁切、短任務、里程碑、來源註記、每週刻度、多年刻度和完整標題換行。原 Firebase effects 的同步清理邏輯保留，只有該區塊有附理由的 `set-state-in-effect` 規則例外。

本輪 Chrome 示範測試通過：搜尋、列表編輯、新增、錯誤日期、開始／完成、CSV 下載、取消刪除、五個頁面、老師唯讀控制，以及 1440px／390px 頁面溢出檢查。示範操作沒有 Firestore／Auth 網路請求。桌面與手機總覽、登入、行事曆、甘特圖、排行榜已做畫面檢查。

實際 Google 登入、跨帳號權限、老師審核、Discord 收訊與正式資料寫入仍須測試帳號驗收；本輪沒有對正式資料做操作測試、沒有修改 Firestore rules 或 Firebase 專案設定，也沒有部署正式網站。

## 結構

### 甘特圖提報

以網頁「提報模式」為主要展示方式：隱藏網站側欄，保留尺度切換和匯出；按 Escape 或「結束提報」返回。長清單及寬圖可捲動，任務欄固定以方便對照。

若要插入投影片，使用 PNG；需要放大或後續排版則使用 SVG。兩者來自同一張 SVG 圖表，包含完整篩選結果、專題名稱、顯示區間、時區、來源註記及更新時間，不是擷取可見畫面。PNG 以最高 2 倍解析度輸出，單邊限制 8192px；過大時提示縮小區間或改用 SVG。

甘特圖不新增另一套排程資料：未填開始時採建立時間，未填截止時採完成時間，並以 † 標示。原本「開始任務」仍會更新開始時間，因此這張圖表是目前儲存的任務時程，並非獨立的基準計畫／實際進度比較圖。

本輪另以 Chrome 驗證日期區間、日／週／月尺度、錯誤日期、篩選、調色、排序、PNG／SVG 下載、提報模式與 Escape 返回、手機版橫向捲動；匯出 PNG 已實際開啟檢查。

### 原始碼

- `src/pages/Dashboard.jsx`：原 Firebase 與工作室流程、全頁共用新增及編輯。
- `src/components/`：總覽與一致的 SVG 圖示。
- `src/lib/tasks.js`：可獨立測試的搜尋、排序、日期與 CSV 工具。
- `src/lib/demo.js`：記憶體示範資料。
- `src/components/GanttChart.jsx`、`src/lib/gantt.js`、`src/gantt.css`：精確時間軸、提報與圖檔匯出。
- `src/workspace.css`：新版樣式及既有 Tailwind 元件相容樣式。
- `PRODUCT.md`、`DESIGN.md`：產品限制與設計紀錄。

字體使用 Google Fonts，無網路時回退系統字體。正式 bundle 包含 Firebase，建置仍有 JS 超過 500 kB 的提示。npm 安裝亦回報既有相依套件 advisories；本輪未進行可能影響 worker 的套件升級。
